# 📝 Smart Task Planner

A simple and interactive Task Planner web app built with HTML, CSS, and Vanilla JavaScript. Created to practice fundamental front-end development concepts and DOM manipulation.

---

## ✨ Features

* ➕ **Add & Delete Tasks:** Easily manage daily tasks.
* 💾 **LocalStorage Integration:** Keeps your tasks saved even after page refresh.
* 🔍 **Task Filter:** View tasks by All, Active, or Completed status.
* 📊 **Task Counter:** Displays the number of remaining active tasks dynamically.
* 🧹 **Clear Completed:** Quickly remove all finished tasks with one click.

---

## 🛠️ Tech Stack

* **HTML5**
* **CSS3**
* **JavaScript (ES6+)**
* **Browser LocalStorage API**

---

## 💡 What I Learned

* Working with JavaScript DOM Manipulation and Event Listeners.
* Storing and retrieving data using Browser `localStorage`.
* Building structured layouts using HTML and CSS.

---

## 🚀 How to Run

1. Download or clone this repository.
2. Open `index.html` in any web browser.
